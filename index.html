Case Study 01 — AI Workflow Audit

Mapping Where AI Helps and Where It Gets in the Way

Problem

I did not know where AI should be used and where it should not. Everyone said "use AI" — but no one explained which tasks it actually helps with.

What I Did

Listed my real weekly tasks — CS coursework, internship, side projects. Classified each one: AI only, human only, or collaborate. Wrote an honest reason per task.

Outcome

First time my AI use was intentional — not random. Built a proof statement that is actually mine: "I build AI agent projects to solve specific problems faced by small business owners."

Case Study 02 — Prompt Engineering

From "Help Me With My Code" to a Reusable Debugging Template

Problem

Weak prompts return weak outputs. "Help me with my code" got three questions back — zero help.

What I Did

Ran 5 iterations, each adding one named technique: role assignment, context, few-shot examples, output structure, step decomposition. Tested final prompt on both Claude and ChatGPT.

Outcome

Version 3 did not help — proved format without real code is useless. Final template works for any beginner Python debugging task. Claude followed format strictly; ChatGPT added useful detail but broke structure.
